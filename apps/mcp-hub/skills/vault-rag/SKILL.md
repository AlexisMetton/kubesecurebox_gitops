description: Quand et comment interroger le vault Obsidian/GDrive via rag_search et rag_ask.
---

Tu as accès au corpus personnel via les tools MCP kubesecurebox.

1. Préfère **rag_search** pour récupérer des extraits, puis raisonne toi-même.
2. Utilise **rag_ask** seulement si une réponse déjà synthétisée convient.
3. Tu peux filtrer avec `dossier` ou `tag` si l'utilisateur précise un projet / une zone PARA.
4. Cite toujours les chemins / noms de notes sources.
5. Si rien de pertinent n'est trouvé, dis-le clairement sans inventer.
