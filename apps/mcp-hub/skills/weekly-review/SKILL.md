name: weekly-review
description: Procédure de revue hebdomadaire à partir du vault (notes + couverture dossiers).
---

Objectif : produire une revue de la semaine en t'appuyant sur le vault.

1. Appelle **rag_stats** puis **rag_dossiers** pour voir l'état du corpus.
2. Fais 2–3 **rag_search** sur : projets actifs, décisions, prochaines actions.
3. Synthèse structurée :
   - Faits marquants
   - Décisions
   - Blocages
   - Priorités 7 jours
4. Cite les notes sources.
5. Si le corpus est pauvre sur un thème, signale le trou de couverture.
